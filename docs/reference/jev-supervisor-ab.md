# Operational supervisor A/B: first behavioral replay

Frozen four synthetic scenarios, two actual Jev calls per scenario. A runs actual
registered stop-hook events; B adds production auditWithJev. Independent reviewer
then proposes actions; a separate replay executes proposals through the parent
handoff and real isolated TaskManagers. No production task/memory/skill writes.

| Scenario | A existing stop hook | B Jev review need (both trials) | Independent review/action |
|---|---|---|---|
| Multi-step work, no task ledger | Quiet | task_review | Confirm; create pending documentation task |
| Ledger still tracks superseded goal | Reconciliation wake | task_review | Confirm; create current-goal task and note stale old task |
| Completed work, ledger current | Quiet | none | Agree quiet; no changes |
| Explicitly waiting on worker | Quiet | none | Agree quiet; no changes |

All proposed isolated mutations succeeded. No task completed/deleted; quiet ledgers
unchanged. The stale case already receives an A warning, so no incremental detection
credit there. Missing-task case is the only demonstrated added coverage. Reviewer
rejected hypothetical intervention on quiet cases; Jev itself did not alert there.

Eight Jev calls took199–728ms each. Work-state wording on missing-task case varied
progressing/drift, while task_review was consistent. Those labels must not be used
as authoritative state. Zero observed false alerts on two quiet fixtures is NOT
an estimated production false-positive rate.

## Reproduction

```
PI_SWARM_SUPERVISOR_AB=1 npx vitest run .pi/test/context/supervisor-ab.local.test.ts
PI_SWARM_SUPERVISOR_AB_ACTIONS=1 npx vitest run .pi/test/context/supervisor-ab-actions.local.test.ts
```

First command needs key in environment; second uses frozen reviewer artifact.
Artifacts under ignored artifacts/supervisor-ab include cases, API results,
independent verdicts and actual task snapshots before/after. Labels were declared
before calls, but cases/rubric are developer-authored development tests.

## Limits

Not autonomous end-to-end A/B: main task work is scripted fixture evidence,
reviewer is an independently invoked agent, and task operations are replayed after
review rather than generated by a live fork worker during task execution. Baseline
is stop-hook behavior, not all possible earlier missing-task enforcement triggers.
Waiting data is richer than live wrapper currently supplies. No runtime budget,
compaction, skill-cleanup quality, vault-correlation or productivity improvement
can be inferred. Do not replace all hooks from these results.
